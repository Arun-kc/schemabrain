# Premium architecture diagram — source files

The interactive Premium architecture diagram embedded at the top of
`/docs/architecture.mdx` is rendered from a self-contained HTML mini-app
generated by Claude Design.

## Files

| File | Purpose |
|---|---|
| `index.html` | Original Claude Design export — the React-based interactive scene |
| `arch-app.jsx` | Top-level React app (tab state, scene composition) |
| `arch-premium-modules.jsx` | The module cards (Agent, MCP server, DB, audit) |
| `arch-premium-connectors.jsx` | The animated SVG connectors + flow captions |
| `assets/schemabrain-mark-dark.svg` | Brand mark used in the scene header |
| `assets/favicon.svg` | Favicon (not visible in iframe but kept for source fidelity) |

## How the embed works

The diagram lives in `docs/architecture.mdx` as an `<iframe srcDoc={...}>`
with the full self-contained HTML inlined as a JS template literal. The
inlining happens because:

1. Mintlify's Next.js router does not serve arbitrary `.html` files from
   sub-folders, so we can't iframe via relative `src=`.
2. Inlining via `srcDoc` keeps the diagram embedded with zero external
   dependencies and zero deploy-time wiring.

## Rebuilding the inlined srcDoc

When the design is updated (new Claude Design export, or hand-edits to the
JSX), regenerate the inlined HTML and patch `architecture.mdx`:

```python
# From repo root:
python3 - <<'EOF'
from pathlib import Path
import base64, re

root = Path("docs/assets/architecture")
html = (root / "index.html").read_text()

# 1) Inline the 3 JSX scripts
for jsx in ("arch-premium-modules.jsx", "arch-premium-connectors.jsx", "arch-app.jsx"):
    body = (root / jsx).read_text()
    html = html.replace(
        f'<script type="text/babel" src="{jsx}"></script>',
        f'<script type="text/babel">\n{body}\n</script>',
    )

# 2) Inline the 2 SVG asset references as data URIs
for svg in ("schemabrain-mark-dark.svg", "favicon.svg"):
    b64 = base64.b64encode((root / "assets" / svg).read_bytes()).decode()
    html = html.replace(f"assets/{svg}", f"data:image/svg+xml;base64,{b64}")

# 3) Escape for JS template literal
escaped = html.replace("\\", "\\\\").replace("`", "\\`").replace("${", "\\${")

# 4) Splice into architecture.mdx between the iframe srcDoc backticks
mdx = Path("docs/architecture.mdx").read_text()
mdx = re.sub(
    r"srcDoc=\{`.*?`\}",
    f"srcDoc={{`{escaped}`}}",
    mdx,
    count=1,
    flags=re.DOTALL,
)
Path("docs/architecture.mdx").write_text(mdx)
print("re-inlined architecture iframe")
EOF
```

Then verify via `cd docs && npx mint@latest dev` → `http://localhost:3000/architecture`.
